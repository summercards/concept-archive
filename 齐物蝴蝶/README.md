## 这一版讲了什么

- **入梦缘由**：一份无署名委托。委托人不进屋，只交来任务书、写明期限的委托函、一个不许追问的问题；报酬是「一段你确实丢掉的过去」——与梦的许诺同源。
- **主线**：寻找真相、逃脱梦境。被同化只是威胁与干扰，不是结局。
- **视觉语言**：巨物、重复、不合理构造；虚焦，焦内保交互可读，焦外显蝶与远景。
- **三个梦域**：雾白林庭、赭粉眠谷、深水灯庭。
- **心理恐怖四种机制**：被认识、追溯改写、被要求自证、被要求「同意一次」。不靠血浆、突袭，不把精神疾病当怪物。
- **贯穿道具**：蝶。《庄子·齐物论》庄周梦蝶原文作开场与任务书指引。
