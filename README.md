# 概念仓

一个装概念的仓库。**每个子目录是一个概念，各自有自己的主页**，根目录是总目录页，链到每一个概念。

## 结构

```
概念仓/
├── index.html          # 总目录（由 tools/build_index.py 生成，不要手改）
├── concepts.json       # 概念清单：目录名、标题、分类、一句话
├── assets/base.css     # 全站共用样式（新概念不许另抄一份）
├── tools/build_index.py
└── 齐物蝴蝶/
    └── index.html      # 该概念自己的主页
```

## 加一个新概念

1. 建目录，例如 `概念仓/新概念/index.html`
2. 在 `concepts.json` 的 `concepts` 数组里加一条：
   ```json
   { "dir": "新概念", "name": "新概念", "tag": "分类", "desc": "一句话说清它在问什么", "date": "2026-11-15" }
   ```
3. 跑 `python3 tools/build_index.py` 重新生成总目录
4. 提交

## 两条规矩

- 概念页只引用 `../assets/base.css`，不复制样式；要加公共样式就改 base.css。
- 概念先存住，不急着做成产品。成形了再单独立项目。
